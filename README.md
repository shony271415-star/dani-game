# טולוז: הרפתקת החטיפים 🐾

משחק התאמה-3 (בסגנון המשחקים מהפרסומות) שבו טולוז החתול הוא הדמות הראשית — נבנה במיוחד בשביל דני 💖

## איך משחקים
- פותחים את `index.html` בדפדפן (עובד הכי טוב בטלפון).
- מחליקים חטיף לצד כדי ליצור 3 זהים בשורה או בטור.
- **4 בשורה** ← חטיף פסים ⚡ שמפוצץ שורה/טור שלם
- **צורת L / T** ← פצצה 💥
- **5 בשורה** ← כף רגל קסומה 🐾 שמנקה צבע שלם
- אפשר להחליף שני חטיפים מיוחדים אחד עם השני לקומבו ענק!

## מה יש במשחק
- 200 שלבים ב-10 פרקים (הסלון, המטבח, הגינה, ... ארמון החטיפים 👑)
- מטרות: איסוף חטיפים, שבירת קרח 🧊, פינוי קופסאות 📦
- שלבים קשים 🔥 כל 10 שלבים
- כוכבים, מטבעות, פטיש 🔨 וערבוב 🔀, +5 מהלכים כשנגמרים
- מתנה יומית 🎁
- "טולוז מטורף!" בסוף שלב — המהלכים שנשארו הופכים לפיצוצים
- צלילים (כולל מיאו 😺) והתקדמות שנשמרת בדפדפן
