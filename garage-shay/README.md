# אתר מוסך שי שירותי רכב

אתר חדש, מהיר ומותאם לנייד, לעסק **מוסך שי שירותי רכב** בראשון לציון.
האתר בנוי מקבצים סטטיים (HTML/CSS/JS), בלי שרת, בלי מסד נתונים ובלי מערכת ניהול.

## איך מעדכנים פרטים?
כל התוכן נמצא בקובץ אחד: **`config.js`**.
פותחים אותו בכל עורך טקסט ומשנים: טלפון, וואטסאפ, כתובת, שעות פעילות, שירותים,
ביקורות, מותגים, טיפים ופרטי נגישות. שומרים, וזה הכול.

## מה יש באתר
- כפתורי חיוג ווואטסאפ קבועים בנייד
- טופס הזמנת טיפול ששולח את הפרטים ישר לוואטסאפ של המוסך
- שירותים, אודות, תעודות BOSCH, סרטון "יצאת צדיק", מותגים, ביקורות, טיפים
- שעות פעילות (כולל "פתוח היום"), מפה, ניווט ב-Waze ו-Google Maps
- הצהרת נגישות

## איך מעלים לאוויר
מעלים את כל התיקייה (`index.html`, `styles.css`, `config.js`, `app.js`, `images/`)
לכל אחסון סטטי: Netlify, GitHub Pages, Vercel, או האחסון הקיים של האתר.
