# מירוץ חי: הקמת Firebase (פעם אחת)

הקוד מוכן. עד שממלאים את ההגדרות ב-`net.js`, הכפתור "מירוץ חי" לא מופיע במשחק, ושום מידע לא נשלח החוצה.

## 1. חשבון נפרד
- להשתמש בחשבון Google ייעודי של המשחק (לא האישי).
- להיכנס ל-https://console.firebase.google.com ולפתוח פרויקט חדש בשם `crime-grid`.
- Google Analytics: לבטל.
- התוכנית החינמית (Spark) מספיקה בהתחלה, ולא צריך כרטיס אשראי.
  - לפי תיעוד Firebase (כדאי לאמת): עד 100 חיבורים בו-זמנית. כל מירוץ תופס 2 חיבורים, כלומר בערך 50 מירוצים במקביל.

## 2. כניסה אנונימית
- Build → Authentication → Get started.
- בלשונית Sign-in method: להפעיל **Anonymous**.

## 3. מסד נתונים
1. Build → Realtime Database → Create Database.
2. מיקום: `europe-west1`.
3. להתחיל ב-locked mode.
4. בלשונית Rules: למחוק את מה שיש, להדביק את כל התוכן של `store/database.rules.json`, וללחוץ Publish.

## 4. הפרטים שצריך לשלוח לי
- Project settings (גלגל השיניים) → General → Your apps → להוסיף אפליקציית Web (`</>`), בלי Hosting.
- להעתיק שני ערכים:
  - `apiKey`
  - `databaseURL`
- הם לא סודיים: הם תמיד גלויים בקוד של אתר. את האבטחה עושים החוקים מסעיף 3.

## 5. הגבלת המפתח
- https://console.cloud.google.com → לבחור את הפרויקט → APIs & Services → Credentials → המפתח "Browser key".
- Application restrictions: לבחור **Websites** ולהוסיף:
  - `https://shony271415-star.github.io/*`
  - אם עוברים לדומיין או לריפו אחר, להוסיף גם אותו.
- API restrictions: להשאיר את מה ש-Firebase יצר.
- לא נבדק: האם עטיפת ה-TWA שולחת את אותו referrer. אחרי הבנייה צריך לבדוק במכשיר אמיתי.

## 6. Play Console: Data safety
כשהמירוץ פעיל, התשובה כבר לא "אין איסוף נתונים":
- **Data collected:**
  - App activity → Other actions (התקדמות וזמן במירוץ)
  - App info and performance? לא.
  - Personal info → Name? הכינוי חופשי ולא חייב להיות שם אמיתי. אם יש ספק, עדיף לסמן "Name" כ-Optional.
  - Device or other IDs: מזהה אקראי של המשחק.
- **מטרה:** App functionality.
- **הצפנה בהעברה:** כן (HTTPS).
- **Ephemeral:** הנתונים נמחקים אחרי המירוץ או תוך יום בערך.
- **אפשר לבקש מחיקה:** דרך המייל הציבורי.
- **שיתוף עם צד שלישי:** Google Firebase פועלת כמעבד בשם המפתח, ולכן לרוב זה לא נחשב "sharing". כדאי לאמת לפי ההנחיות בקונסולה.
- בדירוג IARC: לענות "Users can interact": כן, היריב רואה את הכינוי שלכם. אין צ'אט.

## מה המשחק שומר על המירוץ
מפורט במדיניות הפרטיות (`privacy.html`, סעיף "Live races"):
- קוד מירוץ
- מספר התיק
- כינוי
- חבילת סקין
- שלב במסע
- מספר תיקים שנפתרו
- מזהה אקראי
- האם השחקן חדש
- כמה חשודים הוצבו
- זמן סיום

## בונוס הזמנה
- שחקן חדש שמסיים מירוץ עם מי שהזמין אותו: שניהם מקבלים **500 מטבעות** ואת החבילה הבלעדית **Partners in Crime**.
- המגבלה: עד 5 חברים למזמין.
- הבונוס ניתן על משחק משותף, לא על התקנה, דירוג או ביקורת.
- גוגל ממליצה באופן כללי להימנע מתמריצים. מה שאסור במפורש הוא תמריץ להתקנה שמטרתו להעלות את הדירוג בחנות.
  - לכן, בטקסטים בחנות ובשיווק: לא לכתוב "הורידו וקבלו".
  - כן לכתוב: "שחקו מירוץ עם חבר חדש ושניכם מקבלים".
- אין שרת שבודק רמאות. מי שפותח את הקישור של עצמו בדפדפן שני יכול לקבל את הבונוס. לכן יש תקרה של 5, ולכן החבילה היא קוסמטית בלבד.
